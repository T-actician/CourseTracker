COURSE TRACKER  (gold-on-black, like PixShift)
==============================================
1. Python 3.10+ must be installed (tick "Add Python to PATH").
2. Try it now: double-click run.bat
3. Make the .exe: double-click build.bat -> dist\CourseTracker.exe

FIRST RUN
  Import page -> "Choose document" -> pick your course file (.docx, .txt or .md),
  or paste the text into the box and press "Import pasted text".
  Importing again later is safe: notes and ticks are kept.

PAGES
  Dashboard  stats, next-up day, all weeks with clickable day chips
  Today      jumps to your first unfinished day
  Search     search lessons, checklists and your notes (Ctrl+F)
  Timer      your 45/60/90/30/15 study blocks
  Import     load / paste the course
  Settings   notes text size, colour theme, export/import progress

Data: %APPDATA%\CourseTracker\data.json
